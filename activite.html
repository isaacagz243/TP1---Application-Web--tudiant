Initiation à Git et GitHub

Organisé par le Club informatique

Description

Git est l'outil de gestion de versions utilisé par la grande majorité des équipes de développement. Cet atelier pratique de trois heures vous permettra de maîtriser les bases nécessaires pour vos travaux d'équipe à l'université et vos futurs stages.

Aucune expérience préalable n'est requise. Les ordinateurs du laboratoire sont déjà configurés, mais vous pouvez apporter votre portable si vous préférez travailler sur votre propre machine.

Au programme

  • Créer un dépôt et enregistrer ses modifications (commits)
  • Publier son projet sur GitHub
  • Travailler en équipe avec les branches
  • Proposer et réviser des changements avec les pull requests
  • Résoudre un conflit de fusion
